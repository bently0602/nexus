# T_145: Add Independent SQL Modeler Inspector Scrolling

## Status

Done

## Summary

Keep the SQL data-model diagram fixed in its workspace while allowing the modal's right-hand table
and column inspector to scroll independently when its controls exceed the available window height.

## Proposed Behavior

- Constrain the SQL modeler host and workspace to the modal window's available height.
- Prevent long inspector content from increasing the diagram workspace height.
- Give the right-hand inspector its own vertical scrollbar while preserving its current width and
  controls.
- Keep the diagram canvas usable without requiring it to scroll merely to reach inspector fields.
- Preserve the existing independently scrollable SQL preview section when it is open.

## Acceptance Criteria

1. A selected table with enough columns to exceed the visible right panel produces a vertical
   scrollbar inside the inspector.
2. Scrolling the inspector does not scroll or resize the diagram canvas.
3. The inspector fits the available workspace height below the top toolbar and any error banner.
4. The SQL preview continues to occupy its bounded section without breaking inspector scrolling.
5. Automated coverage verifies the height and overflow layout contract; lint, tests, and build pass.

## Verification

- Replaced the host's page-growing minimum height with a viewport-constrained flex/grid layout.
- Added independent vertical overflow to the right-hand inspector and kept the diagram canvas fixed.
- Kept the optional SQL preview bounded as a separate scrollable flex section.
- `npm run test` — 68 files and 602 tests passed.
- `npm run lint` — passed.
- `npm run build` — TypeScript and the production Vite build passed.
